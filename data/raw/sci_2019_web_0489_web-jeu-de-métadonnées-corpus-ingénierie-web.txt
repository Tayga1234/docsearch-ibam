Jeu de métadonnées — corpus ingénierie web

Auteurs : P. Nikièma (ANPTIC), C. Yaméogo (UJKZ), D. Somé (IBAM)
Année : 2019
Type : dataset
Domaine : Ingénierie web
Revue / support : Revue africaine d'informatique appliquée
Mots-clés : composant, état client, HTTP, Vite, React, informatique

Résumé
Cet article traite de « Jeu de métadonnées — corpus ingénierie web » dans le domaine ingénierie web. Nous présentons une revue systématique de la littérature, centrée sur composant, état client, HTTP. Les résultats indiquent que l'approche retenue distingue clairement parcours sans index et moteur à index. Les apports portent sur la conception, l'implémentation et l'évaluation d'un système d'information documentaire reproductible.

Introduction
Les limites concernent l'absence d'une collection annotée type TREC et l'approximation sémantique du TF-IDF face aux embeddings denses. En perspective, un moteur Meilisearch, un OCR asynchrone et un annuaire LDAP permettraient une mise en production sur le campus. Le prototype DocSearch illustre ces choix en local : extraction multi-formats, enrichissement, Whoosh et similarité TF-IDF. Dans le champ ingénierie web, la notion de React reste centrale pour comprendre la qualité des réponses.
