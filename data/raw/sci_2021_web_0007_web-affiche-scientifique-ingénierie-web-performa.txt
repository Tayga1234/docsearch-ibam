Affiche scientifique — Ingénierie web / performance front

Auteurs : D. Somé (IBAM), S. Traoré (Université Nazi Boni), G. KOROGO (IBAM / MISIE), E. Tapsoba (IBAM)
Année : 2021
Type : poster
Domaine : Ingénierie web
Revue / support : Conférence SI et développement
Mots-clés : HTTP, état client, React, composant, JSON, informatique

Résumé
Cet article traite de « Affiche scientifique — Ingénierie web / performance front » dans le domaine ingénierie web. Nous présentons une comparaison de trois approches d'indexation, centrée sur HTTP, état client, React. Les résultats indiquent que l'approche retenue confirme la faisabilité d'un prototype local. Les apports portent sur la conception, l'implémentation et l'évaluation d'un système d'information documentaire reproductible.

Introduction
En perspective, un moteur Meilisearch, un OCR asynchrone et un annuaire LDAP permettraient une mise en production sur le campus. Notre protocole mesure le temps d'indexation, la latence de requête et l'exploitabilité qualitative des extraits. Les limites concernent l'absence d'une collection annotée type TREC et l'approximation sémantique du TF-IDF face aux embeddings denses. Le prototype DocSearch illustre ces choix en local : extraction multi-formats, enrichissement, Whoosh et similarité TF-IDF.
