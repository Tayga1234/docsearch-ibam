Auteurs : B. Lingani (UJKZ), I. Sawadogo (2iE), Y. Ouattara (ESI)
Année : 2022
Type : note_technique

Revue / support : Bulletin technique ANPTIC

Résumé
Cet article traite de « Retour d'expérience : API REST dans un portail documentaire » dans le domaine architecture logicielle. Nous présentons une expérimentation sur un corpus de démonstration, centrée sur ingestion, pipeline, API REST. Les résultats indiquent que l'approche retenue met en évidence le rôle des métadonnées dans le ranking. Les apports portent sur la conception, l'implémentation et l'évaluation d'un système d'information documentaire reproductible.
