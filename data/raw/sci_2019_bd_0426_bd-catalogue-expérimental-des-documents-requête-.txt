Catalogue expérimental des documents requête SQL

Auteurs : I. Sawadogo (2iE), E. Tapsoba (IBAM), L. Compaoré (Université Thomas Sankara), A. Kaboré (UJKZ)
Année : 2019
Type : dataset
Domaine : Bases de données
Revue / support : Bulletin technique ANPTIC
Mots-clés : index B-tree, requête SQL, PostgreSQL, normalisation, NoSQL, évaluation expérimentale

Résumé
Cet article traite de « Catalogue expérimental des documents requête SQL » dans le domaine bases de données. Nous présentons une analyse de pipeline d'ingestion multi-formats, centrée sur index B-tree, requête SQL, PostgreSQL. Les résultats indiquent que l'approche retenue montre l'intérêt d'un enrichissement déterministe. Les apports portent sur la conception, l'implémentation et l'évaluation d'un système d'information documentaire reproductible.
