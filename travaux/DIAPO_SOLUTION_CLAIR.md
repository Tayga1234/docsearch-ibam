# Diapo Solution — texte clarifié

## À mettre sur la diapo

**Titre :** 4. Solution proposée : DocuSearch

**Phrase d’ouverture**  
Un portail local qui suit un parcours complet :

**ingestion → extraction → enrichissement → indexation → recherche**

| Étape | En une phrase |
|-------|----------------|
| **Ingestion** | Découvrir les fichiers et les préparer avant indexation |
| **Extraction** | Récupérer le contenu utile (ex. texte d’un PDF ou d’un Word) |
| **Enrichissement** | Ajouter résumé, tags, entités et métadonnées |
| **Indexation** | Transformer les documents en un index pour les retrouver vite |
| **Recherche** | Interroger le corpus via l’interface web |

**Plus-value**  
L’enrichissement ajoute automatiquement : **tags**, **résumé** et **entités**.

**3 modes de recherche** (adaptés aux ressources limitées) :
1. **Mots-clés** — correspondance exacte des termes  
2. **Sémantique** — rapprochement par le sens  
3. **Hybride** — combinaison des deux  

---

## Texte oral (≈ 50 s)

> « La solution que nous proposons s’appelle **DocuSearch**.  
> C’est un **portail local** qui suit un parcours clair :  
> **ingestion**, puis **extraction**, puis **enrichissement**, puis **indexation**, et enfin **recherche**.  
>  
> Concrètement : on découvre les fichiers, on récupère leur contenu, on les enrichit avec un résumé, des tags et des entités, puis on les indexe pour les retrouver rapidement.  
>  
> Pour la recherche, nous avons prévu **trois modes** : mots-clés, sémantique et hybride.  
> Ce choix est adapté à un contexte à **ressources limitées** : pas besoin de cloud ni de GPU. »
